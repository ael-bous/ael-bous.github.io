Case studies

Seven more projects, laid out the way I run them: the context, the challenge, my role, the method and what I delivered. The company's performance figures are not published here.

  1. 02Meta Ads campaignsPaid media · Lead generation
    Context
    Amiyas Import sells industrial machinery to business customers.
    Challenge
    Reach the right buyers on Facebook and Instagram, and get real enquiries rather than likes.
    My role
    I run the company's ad campaigns, from setup to monitoring.
    Approach
    Set a goal for each campaign, define the audiences, then match the ad and its destination: the website, WhatsApp or a lead form.
    Execution
    Campaign setup in Meta Ads Manager, ad visuals and copy, lead generation campaigns, regular monitoring and adjustments.
    Tools
    Meta Ads Manager, Facebook, Instagram
    Deliverables
    Campaigns run on Facebook and Instagram, with ads designed in-house. Performance figures stay internal to the company.
  2. 03Lead capture and follow-upLeads and CRM · Automation
    Context
    Enquiries come in through several channels: Meta Lead Ads forms, WhatsApp, and Facebook and Instagram messages.
    Challenge
    Lose no enquiry and hand it to the sales team quickly, without copying contacts by hand.
    My role
    I connect the marketing campaigns with sales follow-up.
    Approach
    Bring every lead into one sheet, with the same details for each contact, then automate how they arrive.
    Execution
    A Make scenario that pulls leads from Meta forms into Google Sheets, a structured follow-up sheet, coordination between marketing and sales.
    Tools
    Meta Lead Ads, Make, Google Sheets, WhatsApp Business
    Deliverables
    An automated flow from lead forms to the follow-up sheet, and an organised lead base for sales follow-up.
  3. 04SEO and online visibilitySEO · Local search
    Context
    The website has to be found by buyers searching Google for a specific machine.
    Challenge
    Make the catalogue readable for search engines and make the company visible in local search.
    My role
    I handle SEO for the website I built.
    Approach
    Get the technical base right, then the content of each page, then the local presence.
    Execution
    Page and heading structure, product page copy and markup, mobile layout and site speed, Google Business Profile listing, site performance monitoring.
    Tools
    Google Business Profile
    Deliverables
    A website structured for organic search and a managed Google Business Profile listing.
  4. 05SISTEP 2026Event marketing · Social media

    Approach

    Execution

    Tools

    Deliverables
    Content and campaigns prepared for the event, supporting brand visibility.
  5. 06Tech Center AcademyOngoingBranding · Positioning

  6. 07Social media and contentContent · B2B communication
    Context
    Amiyas Import communicates with business customers on Facebook, Instagram, LinkedIn and TikTok.
    Challenge
    Explain technical products clearly and keep a steady presence across four networks.
    My role
    I manage the accounts, from planning to publishing and replying.
    Approach
    An editorial calendar, formats suited to each network, and one visual identity everywhere.
    Execution

    Tools

    Deliverables

  7. 08This portfolioWeb development · UI/UX · Personal branding
    Context
    A bilingual portfolio for a profile that combines marketing, technology and creativity.
    Challenge
    Make that profile clear in a few minutes, with no stock imagery and no figures that cannot be checked.
    My role
    I set the positioning and the content, approve the visual direction, then review, test and publish each version.
    Approach
    AI-assisted development: Claude Code writes and edits the code from my instructions, and I approve each step before it goes live.
    Execution
    A static site in French and English generated by a Node.js script, GSAP animation, a WebGL effect, versioned on GitHub and hosted on GitHub Pages.
    Tools
    HTML, CSS, JavaScript, Node.js, GSAP, WebGL, Git, GitHub Pages, Claude Code, Lighthouse
    Deliverables
    A bilingual, mobile-friendly site that respects the reduced-motion setting and has been audited with Lighthouse.
